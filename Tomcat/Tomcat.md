




ENVIRONMENT VARIABLES


\$CATALINA_HOME - directory where tomcat is installed

\$CATALINA_BASE - the directory of a particular instance of Tomcat, if
not set it gets the value of \$CATALINA_HOME




IMPORTANT


Document Root - top level directory of a web application

Context Path - location which is relative to the servers address and
represents the name of the web app





Note: Web applications are deployed to the \$CATALINA_HOME/webapps
directory
